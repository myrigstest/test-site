# Meie Päev

Responsive one-page starter site for a wedding photographer, built with HTML5, Tailwind CSS (CDN), and vanilla JavaScript.

## Local preview

Open `index.html` in a browser, or serve the repository with any static-file server.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, then select the branch containing `index.html` and the `/ (root)` folder. Save the settings to publish the site.
